# 🚀 PIVOT — Vercel Iframe Wrapper

Folder ini merupakan pembungkus (*wrapper*) Web App PIVOT Google Apps Script berkinerja tinggi yang siap di-deploy secara instan ke platform [Vercel](https://vercel.com).

* **Repositori GitHub:** [santrimanofficial26-oss/aplikasiPIVOT](https://github.com/santrimanofficial26-oss/aplikasiPIVOT.git)
* **Backend Apps Script:** `https://script.google.com/macros/s/AKfycbzAyumyXMI0HvIBFbvJ9S54xw9fSF82oxXvzkMeZNx6S5v4oxWRzCLAS4hYx8Kw7k78Hw/exec`

## 🛠️ Cara Deploy ke Vercel (1 Menit Selesai)
1. Buka dashboard [Vercel](https://vercel.com) dan login dengan akun Anda.
2. Klik tombol **"Add New Project"**.
3. Pilih / Import repositori GitHub: `santrimanofficial26-oss/aplikasiPIVOT`.
4. Pada bagian pengaturan proyek:
   * **Framework Preset:** `Other`
   * **Root Directory:** `./`
   * **Build & Output Settings:** Biarkan default (tidak perlu build command).
5. Klik **"Deploy"**.
6. Aplikasi PIVOT Anda langsung live di domain kustom Vercel (contoh: `aplikasi-pivot.vercel.app`)!

## 🔄 Cara Push Pembaruan Otomatis
Cukup klik ganda (*double-click*) file `push_to_github.bat` atau jalankan `push_to_github.ps1` untuk melakukan update commit & push otomatis ke GitHub.
